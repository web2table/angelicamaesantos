# Angelica Mae M. Santos — Digital Business Card

A compact, responsive digital business card for Angelica Mae M. Santos, Founder & Marketing at Web2Table.

This repository is separate from Jorel's profile and uses the same premium black-and-red single-screen design language.

## GitHub Pages
1. Open **Settings → Pages**.
2. Choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then save.
4. Configure a custom domain in GitHub Pages when ready.
5. Configure DNS at Hostinger according to GitHub Pages instructions and enable HTTPS when available.

Static site; no backend, database, or build workflow required.
