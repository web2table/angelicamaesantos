## GitHub Pages
1. Open Settings → Pages.
2. Choose Deploy from a branch.
3. Select main and /(root), then save.
4. Configure the custom domain when ready.
5. Configure DNS at Hostinger according to GitHub Pages instructions and enable HTTPS when available.

Static site; no backend, database, or build workflow required.
